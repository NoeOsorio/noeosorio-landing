- Pills: TypeScript, Swift, SwiftUI, Node.js
- Primary link: none (private code)

## Essay Studio

- Role line: Personal project, open source
- Description: A desktop writing app where four AI agents question your essay instead of writing it for you.
- Pills: Rust, Tauri, Next.js, TypeScript
- Primary link: Open on GitHub, https://github.com/NoeOsorio/essay-studio
- Gallery: screenshots, captured later
- Features:
  - **Four agents.** Evidence, systems, practice and objections each have their own voice and color. They ask questions and mark your text.
  - **A score you can check.** It starts at 10 and drops with each open finding. You can apply a finding or dismiss it.
  - **Rubric and sources.** Drop an assignment and its criteria appear with their weight. Drop a PDF and the title, authors and citation fill in.
  - **Yours, on your computer.** Essays are saved as files on your machine, with automatic versions and a backup before every restore. You can also create your own agents.
- Timeline:
  - 2026-05-09: Started as a Tauri and Next.js shell with an editor.
  - 2026-11-14: Latest change, a button that rewrites your custom agent instructions to be clearer.
- Bottom link: Open on GitHub, https://github.com/NoeOsorio/essay-studio

## Whiteboard

- Role line: Personal project
- Description: A whiteboard that listens while you talk and draws your notes live.
- Pills: Next.js, React, TypeScript
- Primary link: none (private code)
- Gallery: screenshots, captured later
- Features:
  - **Notes while you speak.** It writes short notes, changes sheets and keeps a teleprompter of what you said.
  - **Corrections respected.** If you correct yourself, the wrong version is crossed out or never written.
  - **Doodles with purpose.** It draws only what can be drawn, like a ship with containers, and never puts text inside a doodle.
  - **Live or recorded.** Start a live class, or upload a voice note and watch the board fill in. It works in Spanish and English, and transcription runs on your Mac or in the cloud.
- Timeline:
  - 2026-11-01: Started with voice notes transcribed on my Mac.
  - 2026-11-14: Latest change, a sheet navigator for live and saved classes.
- Bottom link: none

## Telar

- Role line: Personal project
- Description: A story engine for educational visual novels, where characters act on their own.
- Pills: TypeScript, React, Vite, Ink
- Primary link: none (private code)
- Gallery: screenshots, captured later
- Features:
  - **Scenes, not branches.** Stories are written as independent pieces that appear when the state of the world makes them possible.
  - **Memory with consequences.** A lie in the first act can come due five scenes later.
  - **Characters with their own lives.** Between weeks they act on their own rules, and you find out afterward.
  - **Earned endings.** Nothing is written for everyone. A life ends when something decisive happens, like an expulsion or a scholarship abroad.
- Timeline:
  - 2026-09-23: Started with the engine core and the first worlds in files.
  - 2026-09-27: A private online version published on every update, with La beca redesigned as a school notebook.
- Bottom link: none

## Porter Galaxy

- Role line: Personal project, open source. Not a Porter product.
- Description: A Kubernetes cluster shown as a living 3D galaxy.
- Pills: Go, Three.js, Kubernetes, Helm
- Primary link: Open on GitHub, https://github.com/NoeOsorio/porter-galaxy
- Gallery: screenshots, captured later
- Features:
  - **Two views.** Topology shows how traffic reaches your workloads, from the internet to each Pod. Clusters shows where every Pod runs.
  - **Live.** A Go backend reads the cluster and pushes changes to the browser as they happen. Adding a Pod never rearranges the rest of the map.
  - **Real state.** Pods are colored by their actual status, and one that just restarted pulses. Its panel shows the last termination reason.
  - **Easy to install.** It ships as a Helm chart, and the README walks through deploying it on Porter without the command line.
- Timeline:
  - 2026-03-02: Started.
  - 2026-10-01: Latest change in the repository.
- Bottom link: Open on GitHub, https://github.com/NoeOsorio/porter-galaxy

## Sim World

- Role line: Personal project, open source
- Description: Life simulations in the browser, from the primordial soup to families with personalities.
- Pills: React, TypeScript, Vite
- Primary link: Try it live, https://simulations.noeosorio.com
- Gallery: screenshots, captured later
- Features:
  - **One phase at a time.** Micro Ecosystem, Skill Ecosystem, Tribal Society and Family Bonds. Each adds one new pressure.
  - **Traits that pass on.** Skills and personalities are inherited and mutate, and families keep houses and pantries.
  - **Save and reload.** A run is a plain text file you can load again, and you can export a timestamped log of births, deaths and food.
  - **No backend.** Everything runs in your browser, with speed controls and a full screen view.
- Timeline:
  - 2026-04-23: Started with the first phase, a micro ecosystem.
  - 2026-09-26: Latest change, a full README and an open license.
- Bottom link: Try it live, https://simulations.noeosorio.com

- Description: A point of sale for a stationery store, rebuilt for the web. I did the redesign of the web app.
- Pills: React, TypeScript, Tailwind, FastAPI, PostgreSQL
- Primary link: none (private code)
- Gallery: screenshots, captured later
